# Research methodology and interpretation

The target question is whether supervised fine-tuning improves Canadian knowledge, contextual understanding and factual reliability under a fixed independent judging framework. Evaluate base/fine-tuned responses to paired questions using the same human-approved metric version, judge deployment, evidence and applicability. Preserve training/evaluation separation and document potential contamination. Do not tune rubrics against the held-out final comparison.

The seven constructs are reported separately. No defensible weighting policy has been approved, so the project does not compute a composite score. Human applicability labels define denominators. N/A and judge errors are nulls with different statuses; neither is zero. Report status counts alongside successful-score summaries to expose selective failure.

Per metric and variant, report count, mean, sample standard deviation and median. Paired summaries use questions with both successful scores and preserve missing/failed pairs in unmatched counts. A 95% paired bootstrap interval uses 5000 resamples with seed 2026 only when >=10 valid question pairs exist. Ten is an operational minimum, not a guarantee of sufficient precision; tiny or degenerate samples should be interpreted cautiously. If questions are clustered by source, topic or paraphrase family, independent-question bootstrap assumptions fail: plan a cluster-aware analysis rather than treating these intervals as confirmatory. Multiple metric comparisons and dataset selection bias must be addressed in a publication.

Generated evaluation steps are proposals. Four fresh independent calls per metric expose potential variation; identical proposals are honestly retained. Sampling uses gateway defaults; the project does not invent diversity settings that the gateway has not been tested to support. Record the deployment revision externally if available, since a model ID may point to changing weights. Definition signatures, full prompts, raw outputs, package versions, timestamps and canonical frozen hashes support auditability but do not guarantee that a remote model is immutable.

Consolidation is transparent lexical grouping; final criteria and rubrics require human review. Exploratory draft pilot scores are not approved experimental results. The small provided synthetic examples test software behavior and obvious score direction only; they do not establish general reliability, cultural validity, bilingual fairness, robustness to prompt injection or causal fine-tuning improvement. Run the human calibration protocol before asserting those properties.

Store original model outputs and reference provenance in authorized research storage. Treat prompt-injection text inside responses as untrusted data; generated criteria explicitly instruct judges to assess content rather than obey response instructions, but this cannot guarantee injection resistance. Use held-out adversarial examples to investigate this limitation. Keep the API key out of reports and source control. Obtain data-sharing authorization before sending nonpublic data to the supplied gateway.
